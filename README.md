# Political Party Management System

Desktop management system developed for the administration and maintenance of political party affiliate information.

## Features
- User login with validations
- CRUD operations for affiliate management
- SQL Server relational database integration
- Audit logs for login and system activity tracking
- Electoral registry lookup module
- Administrative forms and data management

## Technologies Used
- Visual Basic .NET
- Windows Forms
- SQL Server
- Visual Studio 2022

## Concepts Applied
- CRUD operations
- Relational databases
- Primary and foreign keys
- Validations
- Audit logging
- Desktop application development
